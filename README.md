# اپلیکیشن اندروید «ایران کمپ» (WebView)

این پروژه یک اپ اندرویدی کامل (Kotlin) است که سایت `https://irancamp.online/` رو داخل خودش لود می‌کنه، دقیقاً همون نسخه‌ای که در مرورگر موبایل می‌بینی.

## امکاناتی که از قبل توش پیاده‌سازی شده
- لود کامل سایت با جاوااسکریپت، DOM Storage و کوکی فعال (لازمه برای لاگین و پنل کاربری)
- پشتیبانی از کوکی‌های Third-party برای درگاه‌های پرداخت ایرانی (زرین‌پال، آیدی‌پی، زیبال، نکست‌پی، شاپرک) — لیست دامنه‌های مجاز رو در `MainActivity.kt` می‌تونی ویرایش کنی
- دکمه Back اندروید که داخل تاریخچه سایت برمی‌گرده
- Pull-to-refresh (کشیدن به پایین برای رفرش)
- نوار پیشرفت لود صفحه
- صفحه‌ی «اتصال اینترنت نیست» با دکمه تلاش مجدد
- آپلود فایل از فرم‌های سایت (مثلاً آپلود مدرک یا عکس پروفایل)
- باز شدن لینک‌های خارج از سایت (مثل شبکه‌های اجتماعی) در مرورگر جدا، نه داخل اپ
- باز کردن صفحاتی که با `target="_blank"` یا `window.open` باز می‌شن (معمولاً صفحه پرداخت)
- امنیت SSL: خطای گواهی نادیده گرفته نمی‌شه (برای پرداخت امن)

## قبل از ساخت اپ (خیلی مهم)
1. **آیکون:** یک آیکون ساده جایگزین گذاشتم (`app/src/main/res/drawable/ic_launcher.xml`). حتماً قبل از انتشار در Android Studio از منوی `New > Image Asset` آیکون واقعی برند خودتون رو جایگزین کنید.
2. **درگاه پرداخت:** اگر سایتت با درگاهی غیر از موارد لیست‌شده کار می‌کنه (مثلاً «به‌پرداخت ملت» یا «آسان‌پرداخت»)، دامنه‌ی اون درگاه رو هم به دو فایل زیر اضافه کن، وگرنه ممکنه صفحه پرداخت در مرورگر خارجی باز بشه یا کوکی درست کار نکنه:
   - `app/src/main/res/xml/network_security_config.xml`
   - `app/src/main/java/com/irancamp/app/MainActivity.kt` (لیست `allowedDomains`)
3. **گوگل لاگین/ورود با شبکه‌های اجتماعی:** اگه سایت از لاگین گوگل یا مشابه استفاده می‌کنه، معمولاً همون WebView کافیه، ولی گوگل گاهی ورود از WebView غیر از Chrome Custom Tabs رو محدود می‌کنه. اگه با این مشکل مواجه شدی، بگو تا نسخه‌ی Chrome Custom Tabs رو هم برات اضافه کنم.

## نحوه‌ی ساخت APK (گام‌به‌گام)
1. [Android Studio](https://developer.android.com/studio) رو نصب کن (رایگان).
2. این پوشه (`IranCampApp`) رو با گزینه‌ی **Open** در Android Studio باز کن (نه Import قدیمی).
3. صبر کن Gradle Sync تموم بشه (اولین بار ممکنه چند دقیقه طول بکشه چون Gradle رو دانلود می‌کنه).
   - اگه پیغام مربوط به گم بودن `gradle-wrapper.jar` دیدی، از منوی بالا `File > Sync Project with Gradle Files` رو بزن؛ Android Studio خودش می‌سازتش.
4. برای تست سریع روی گوشی یا شبیه‌ساز: دکمه‌ی سبز رنگ ▶ (Run) رو بزن.
5. برای گرفتن فایل نصبی نهایی:
   - `Build > Generate Signed Bundle / APK`
   - گزینه APK رو انتخاب کن
   - یک Keystore جدید بساز (اطلاعاتش رو جایی امن نگه دار، برای آپدیت‌های بعدی لازمه)
   - نوع Release رو انتخاب و Finish کن
   - فایل APK نهایی در مسیر `app/release/app-release.apk` ساخته می‌شه

## انتشار در گوگل‌پلی (اختیاری)
گوگل گاهی اپ‌های ساده‌ی WebView رو رد می‌کنه چون ارزش افزوده‌ی کمی نسبت به مرورگر دارن. برای افزایش شانس تأیید:
- حتماً آیکون و اسکرین‌شات واقعی بذار
- Privacy Policy برای سایتت آماده کن (چون لاگین/پرداخت داره، گوگل حتماً می‌خواد)
- در توضیحات اپ مشخص کن چه خدماتی ارائه می‌ده (نه فقط «نمایش سایت»)

## ⭐ ساخت APK در فضای ابری (بدون نیاز به VPN یا Android Studio) — پیشنهاد اصلی

اگه با نصب SDK، دانلود Gradle، یا اتصال VPN مشکل داری (که در ایران خیلی رایجه)، این مسیر رو برو. یه فایل به اسم `.github/workflows/build-apk.yml` توی این پروژه گذاشتم که به گیت‌هاب می‌گه خودش پروژه رو build کنه — روی سرورهای گیت‌هاب که مستقیم و بدون فیلترینگ به گوگل دسترسی دارن.

### مراحل:
1. یه حساب رایگان در [github.com](https://github.com) بساز (اگه نداری).
2. روی گیت‌هاب یه Repository جدید بساز (دکمه‌ی سبز **New**)، اسمش رو مثلاً `IranCampApp` بذار، **Public** یا **Private** فرقی نمی‌کنه، و روی **Create repository** بزن.
3. توی صفحه‌ی خالی Repository، دنبال لینک **"uploading an existing file"** بگرد و روش کلیک کن.
4. کل محتویات پوشه‌ی `IranCampApp` (همون که از zip اکسترکت کردی) رو بکش و داخل اون صفحه رها کن (Drag & Drop). صبر کن آپلود تموم بشه، بعد پایین صفحه دکمه‌ی **Commit changes** رو بزن.
   - نکته: پوشه‌های `.gradle`، `.idea` و `build` (اگه وجود دارن) رو لازم نیست آپلود کنی، سنگین و غیرضروری‌ان.
5. برو به تب **Actions** بالای صفحه‌ی Repository. باید یه ورک‌فلو به اسم "Build APK" رو ببینی که خودش شروع به اجرا شده (چون به `main` پوش کردی). اگه شروع نشده، از پهلو روی "Build APK" بزن و بعد دکمه‌ی **Run workflow** رو بزن.
6. صبر کن (حدود ۳-۵ دقیقه). وقتی علامت سبز ✅ کنار اجرا ظاهر شد، روی همون اجرا کلیک کن.
7. پایین صفحه، قسمت **Artifacts** رو پیدا کن و روی `IranCampApp-debug-apk` کلیک کن تا یه فایل zip دانلود بشه. داخل اون zip، فایل `app-debug.apk` هست — همون فایل نصبی نهایی.
8. این فایل رو به گوشیت منتقل کن و نصبش کن (با فعال کردن "نصب از منابع ناشناس").

این نسخه، نسخه‌ی **Debug** هست (برای تست کامل کار می‌کنه). اگه بعداً خواستی نسخه‌ی Release امضاشده برای گوگل‌پلی بسازی، بگو تا ورک‌فلو رو براش گسترش بدم.

## تغییر آدرس سایت در آینده
اگه دامنه سایت عوض شد، فقط این خط رو در `MainActivity.kt` ویرایش کن:
```kotlin
private val BASE_URL = "https://irancamp.online/"
```
و دامنه‌ی جدید رو به `allowedDomains` و `network_security_config.xml` هم اضافه کن.
